# **App Name**: QuizWhiz

## Core Features:

- Question Display: Displays a set of questions (5 pages of 6 questions).
- Answer Input: Allows users to input text answers for each question.
- Progress Indicator: Displays progress through the questionnaire.
- Page Navigation: Provides navigation buttons to move between pages.

## Style Guidelines:

- Use the Catppuccin Macchiato color palette as the primary theme.
- Accent color: Teal (#4DBAEB) to highlight active elements.
- Use Tailwind CSS for responsive and consistent layout.
- Clean and readable typography for questions and answers.
- Subtle transitions between pages.

## Original User Request:
create a simple React questionnaire app that has 30 questions split into 5 pages. There should also be a progress marker for how many of the questions are done. Below the questions there should be text boxes to record the input. Use tailwind and a dark theme like cattpuccin machiato
